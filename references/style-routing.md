# Style Routing

Use this file when deciding the deck's visual language.

## Style Inputs

Collect or infer:

- Audience: beginner, professional, investor, teacher, creator community.
- Occasion: assignment, report, live talk, product launch, short-video recording.
- Mood: calm, premium, energetic, futuristic, editorial, technical.
- Density: sparse keynote, balanced report, data-heavy deck.
- Brand constraints: colors, logo, font, screenshots, screenshots-only, no brand.

## Style Families

### Guizang Editorial

Use for creator content, AI topics, and visual-first storytelling.

- Large contrast between headline and body.
- Strong cover composition.
- Magazine-like hierarchy.
- Good for screenshots, AI workflow diagrams, and concept pages.

### Swiss Grid

Use for serious analysis, methodology, business logic, and structured reports.

- Clear grid.
- Tight alignment.
- Few colors.
- Strong typography.
- Good for frameworks, comparisons, and tables.

### Apple Keynote

Use for product demos, launches, and short talks.

- Big statement per page.
- Dark or clean light background.
- One visual focus.
- Slow reveal and controlled pacing for motion decks.

### Technical Dashboard

Use for AI tools, workflows, automation, metrics, and product systems.

- Interface screenshots.
- Diagram blocks.
- Status chips and pipeline layouts.
- Keep it restrained; avoid making every page look like a decorative card.

### Creator Short-Video Deck

Use when the deck will become a video.

- Each page must read within 2-4 seconds.
- Use kinetic title pages, zoom-friendly layouts, and strong visual beats.
- Add motion notes to `outline.md`.

## Style Board Must Include

- Style name.
- Keywords.
- Color system.
- Typography direction.
- Layout rules.
- Cover direction.
- Diagram style.
- Motion notes if relevant.
- One thing to avoid.
